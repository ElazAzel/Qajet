# QAJET Desktop (Tauri 2)

Тонкая нативная обёртка над тем же веб-приложением (`apps/web`), не
отдельный фронтенд. Главное окно грузит боевой адрес Vercel напрямую
(`app.windows[0].url` в `src-tauri/tauri.conf.json`) — код экрана
консьержа один и тот же в браузере и в этом приложении.

Поверх веб-приложения Tauri добавляет то, что физически недоступно
браузерной вкладке:

- нативное меню (`О QAJET`, `Настройки…`, `Обновить`, `Выйти`);
- системный трей со сворачиванием в фон;
- глобальный хоткей `⌘⇧Space` / `Ctrl⇧Space`, поднимающий окно из любого
  приложения и посылающий фронтенду событие `global-shortcut:command-palette`
  (перехватывается уже существующей палитрой `⌘K` консьержа, см.
  `packages/ui/src/shell`);
- deep link `qajet://order/...` (протокол зарегистрирован в
  `tauri.conf.json` → `plugins.deep-link`);
- одиночный экземпляр приложения (`tauri-plugin-single-instance`) —
  повторный запуск фокусирует уже открытое окно вместо второго;
- память размера/позиции окна между запусками (`tauri-plugin-window-state`).

## Запуск

```
pnpm --filter @qajet/desktop dev     # окно с hot-reload боевого сайта
pnpm --filter @qajet/desktop build   # релизная сборка под текущую ОС
```

Сборка и пакетирование проверены в этом репозитории на Linux (Ubuntu
24.04): `cargo check`, `tauri build --no-bundle`, и полный `tauri build`
с реальными `.deb`/`.rpm`/`.AppImage` (Ubuntu 24.04 +
libwebkit2gtk-4.1-dev, libjavascriptcoregtk-4.1-dev, libsoup-3.0-dev,
libgtk-3-dev, libayatana-appindicator3-dev, xdg-utils — последний нужен
именно бандлеру AppImage, `tauri build --no-bundle` без него собирает
бинарь, но полная упаковка падает на `xdg-mime binary not found`).
`.dmg`/`.msi` не проверялись — нужны, соответственно, macOS и Windows,
которых нет в песочнице разработки.

## Иконки

`tools/branding/icon-512.png` — тот же бренд-знак, что рендерит
`apps/web/app/icons/[size]/route.tsx` для PWA-манифеста, экспортированный
в файл один раз (нативным инструментам сборки, в отличие от PWA-манифеста,
нужен файл на диске, а не HTTP-маршрут). Регенерация после смены знака:

```
pnpm --filter @qajet/desktop icon
```

## Честно про ограничения

- URL в `tauri.conf.json` — `https://qajet-seven.vercel.app` (текущий
  постоянный алиас Vercel-проекта). Свой домен появится — правится один
  раз здесь и всё.
- Автообновление (`tauri-plugin-updater`) не подключено: требует
  подписанный релиз-канал (приватный ключ, эндпоинт манифеста обновлений),
  который для прототипа без релизной инфраструктуры настраивать
  преждевременно — сначала нужен хотя бы один опубликованный релиз.
