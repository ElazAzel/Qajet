# QAJET: промо-ролик (Remotion)

30 секунд, 1920×1080, 30 fps, ровно 900 кадров. Ролик показывает **реальный путь
покупателя в реальном интерфейсе QAJET**. Экраны не выдуманы: они воссозданы по
исходникам `apps/web` (подписи, структура, токены §12, примитивы движения).

| Сцена | Что происходит | Источник в продукте |
| --- | --- | --- |
| Интро | «Скажите, что нужно купить. / Остальное сделаем мы.» | `apps/web/app/page.tsx` |
| Заявка | Фраза → «Разобрать» → «Что мы поняли» → поля заполняются сами → «Отправить заявку» | `buyer/requests/new/page.tsx`, `@qajet/engine/intake` |
| Закупка | Стадии: Получено → Оценка → Подбираем исполнителей → «Нужно ваше решение», «Сейчас ход за» | `buyer/requests/[id]/page.tsx`, `lib/buyer-stage.ts` |
| Варианты | Три варианта и полосы в единой шкале: дешёвое КП дороже после налогового эффекта | `_plan-alternatives.tsx`, `motion/bar-grow.tsx`, §8D, §12 |
| Подтверждение | Условия, сумма, «Подтверждаю заказ на этих условиях», запись в журнале | `buyer/orders/[id]/confirm/*` |
| Исполнение | Таймлапс стадий до «Завершено», документы, история заказа | `buyer/orders/[id]/_order-view.tsx` |
| Аутро | Три отличия с лендинга, CTA, адрес | `apps/web/app/page.tsx` |

## Что настоящее, а что заглушка

- **Настоящее:** все подписи интерфейса, тексты стадий, причины отбраковки
  (`REJECTION_REASONS` в `combine.ts`), форматы денег и дат, персоны демо-сида,
  токены цвета, радиусы и кривые движения. Разбор фразы запроса — фактический
  вывод `parseRequestText` из `@qajet/engine/intake` на этой фразе.
- **Заглушка** (помечено в `src/content.ts`): суммы вариантов, даты таймлапса,
  счётчики отбраковки, идентификаторы в адресах. Реквизиты на экране
  подтверждения размыты. Имён исполнителей в ролике нет: покупатель их не видит (§10).
- На панели полос есть сноска с лендинга: «Цифры демонстрационные».

Упрощения относительно живого экрана: на странице закупки не показаны карточки
«Подтверждение перевода», «Оцените исполнение» и форма изменения условий.
Действия «Принять поставку» и «Подтвердить сверку и закрыть» нажимаются прямо
в карточке статуса.

## Команды

```bash
cd marketing/promo-video
bun install                       # или npm i

npx remotion studio               # превью (то же: bun run dev)
bun run typecheck                 # tsc

# Финальный рендер: H.264, CRF 18 (то же: bun run render)
npx remotion render QajetDemo out/qajet-demo.mp4 --codec=h264 --crf=18
```

`remotion.config.ts` задаёт `yuv420p` + BT.709: такой профиль ждут соцсети.
Файлы из `out/` в git не попадают. Если Remotion не может скачать Chrome Headless
Shell, укажите свой: `--browser-executable=/путь/к/headless_shell`.

**Шрифт.** Продукт использует системный Helvetica Neue (§12). На macOS ролик
рендерится им же. На Linux и в CI подставляется Arimo (метрически совместим,
есть кириллица), поэтому ширина текста может чуть отличаться.

## Где что менять

| Что | Где |
| --- | --- |
| Тексты интерфейса и демо-данные | `src/content.ts` |
| Цвета, радиусы, шрифт | `src/theme.ts` (= токены `apps/web/app/globals.css`) |
| Длительности сцен | `TIMING` в `src/MainSequence.tsx` (формула суммы в комментарии) |
| Все ключевые кадры пути покупателя | `J` в `src/journey/script.ts` |
| Камера: наезды, отъезды, наклон | `CAMERA_KEYS` в `src/journey/script.ts` |
| Траектория курсора и клики | `CURSOR_PATH`, `CLICKS` в `src/journey/script.ts` |
| Раскладка экранов (и точки кликов) | `A_LAYOUT`, `B_LAYOUT`, `C_LAYOUT` в `src/journey/script.ts` |
| Подписи шагов | `CAPTIONS` в `content.ts`, `CAPTION_TIMES` в `script.ts` |

Точки кликов и фокус камеры считаются из той же раскладки, что и вёрстка.
Если сдвинуть кнопку в `*_LAYOUT`, курсор и камера поедут за ней.

## Структура

```
src/
  Root.tsx, MainSequence.tsx   композиция, TIMING, общий фон
  theme.ts, content.ts         токены продукта, тексты и демо-данные
  journey/script.ts            сценарий: ключевые кадры, раскладка, камера, курсор
  lib/motion.ts                токены движения продукта + кривые ролика
  lib/camera.ts                виртуальная камера над окном браузера
  ui/                          реплика интерфейса: оболочка, примитивы, иконки, страницы
  fx/                          эффекты ролика: курсор, клики, прожектор, подписи,
                               таймлапс, аудит, полосы вариантов, фон сцены
  scenes/                      Intro, Journey, Outro
```

## Remotion agent skills

В репозиторий не коммитятся, версия зафиксирована в `skills-lock.json`. Установка:

```bash
npx skills add remotion-dev/skills -a claude-code --copy -y \
  --skill remotion-best-practices --skill remotion-markup \
  --skill remotion-create --skill remotion-render --skill remotion-studio
```
