- **02:49** Фаза 2 (движок) реализована целиком в packages/engine: money (целочисленная арифметика, распределение остатка методом наибольшего остатка), tax/snr (эффект по вычету КПН у поставщиков на упрощённой декларации), estimate (МНК ln(price)=a+b·ln(qty), байесово сглаживание λ=N/(N+8), P80-квантиль запаса), leadtime (медиана факт/заявлено, сдвиг к 1.0 при малом N), match (жёсткие фильтры, взвешенный скор, онлайн-логрегрессия SGD, Thompson sampling через честную Beta-выборку из двух Gamma-розыгрышей для слота исследования), combine (точный branch-and-bound перебор подмножеств поставщиков ≤8/≤12 позиций с admissible-границей через cheapest-remaining-minus-max-discount, плюс greedy+2-opt эвристика для больших случаев), intake (нормализация, regex на количество/бюджет/срок, нечёткое сопоставление номенклатуры триграммы+Дамерау-Левенштейн порог 0.72), learn/recalibrate (пересчёт всех калибровок сразу). 87 тестов, оба обязательных кейса §15 прошли с первого реального прогона (один поставщик выгоднее трёх — за счёт консолидации доставки и скидки за комплект; эффект СНР меняет победителя — дешёвый оффер у поставщика на упрощёнке становится невыгоднее после эффекта по КПН). Вынес перевод раскладки в отдельную explicit-функцию convertJcukenLayout вместо тихого автоисправления.
