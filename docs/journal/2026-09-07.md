Анимация — не через Motion: прямой импорт `motion/react` из apps/web не резолвится (пакет `motion` — зависимость `@qajet/ui`, а не apps/web, pnpm-strict это ловит на tsc), вместо добавления новой зависимости взял уже принятый в проекте паттерн голых CSS-переходов на токенах длительности/кривых (`transition-[grid-template-rows] duration-[var(--duration-quick)] ease-[var(--ease-standard)]`, тот же приём, что уже используется в `buyer/settings/page.tsx` для тумблера) — высота контента анимируется через `grid-template-rows: 0fr↔1fr`, поворот шеврона через `transform: rotate()`. tsc/biome/`next build` зелёные.
