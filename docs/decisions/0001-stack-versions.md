# ADR-0001 — Версии стека зафиксированы явно

Дата: 2026-09-06
Статус: принято

## Контекст

Пользователь попросил «суперсовременный стек», актуальный на сентябрь 2026.
`agents.md` при этом фиксировал Next.js 15 и shadcn на Radix как исходное
намерение. Актуальность и стабильность иногда расходятся: не всё самое
свежее в реестре npm пригодно для фундамента проекта.

## Решение

Версии в `agents.md` §2 подняты до актуальных стабильных на 06.09.2026, с
двумя намеренными исключениями:

- **TypeScript остаётся на 5.9.3**, не на 7.0 (новый нативный компилятор на
  Go). TS7 меняет модель компиляции достаточно радикально, чтобы совместимость
  с выводом типов Drizzle и Next оставалась непроверенной на дату решения.
  Переход — отдельный ADR, когда экосистема (particularly ts-morph для RAG,
  drizzle-kit) подтвердит поддержку.
- **Vitest остаётся на 4.1.11**, не на 5.0.0 (вышел 03.09.2026, за три дня до
  решения). Слишком свежий релиз для фундамента, на котором строится вся
  дисциплина тестирования движка.

Остальной стек — реальные текущие стабильные версии, проверенные через
`npm view <pkg> version` в момент принятия решения, а не по памяти модели:
Next 16.3.4, Tailwind 4.3.3, Motion 13.2.0 (пакет переименован из
framer-motion, импорт из `motion/react`), Drizzle ORM 0.45.x, Playwright
1.63.x, Recharts 3.10.x, shadcn CLI v4 с явным флагом `--base radix`
(в 2026 дефолт CLI — Base UI, но при глубокой перекраске под токены QAJET
смена примитива компонентов — лишний риск).

## Последствия

`pnpm-workspace.yaml` использует `catalog:` для версий, общих между
пакетами монорепо, чтобы они не расходились при последующих `pnpm add`.
Обновление зафиксированной версии — это правка catalog и новый ADR, а не
побочный эффект `pnpm update`.
