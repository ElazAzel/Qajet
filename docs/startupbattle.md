# Публичная страница для питча

`/startupbattle` — отдельный публичный маршрут существующего приложения
`apps/web`. Основная страница и вход в платформу сохраняются. Страница
рендерится статически, не обращается к Supabase и доступна без авторизации.

## Содержание и источники

- Позиционирование, 9 организаций в исследовании, кейс с бюджетом 2 млн ₸,
  база 300+ поставщиков, команда и цели пилота — из
  предоставленного командой `QAJET.pdf`.
- 225 млн ₸ — расчётный годовой объём закупок первого сегмента, не фактические продажи.
- Сервисная наценка берётся из `COMMISSION_DEFAULT_PCT` (23% в текущей версии) и подписана как гипотеза пилота. Пример считает 172 500 ₸ дохода сервиса с 750 000 ₸ стоимости поставщиков, клиентская цена до доставки 922 500 ₸. Наценка не называется прибылью или бухгалтерской выручкой реселлера. Старый сценарий выручки при 7% убран.
- Цены в интерактивном сравнении — иллюстрация. Доли полос рассчитаны
  относительно единой максимальной стоимости 1 240 000 ₸.
- Шесть скриншотов предоставлены командой и отображают демонстрационные
  данные. Они не служат подтверждением продаж и конверсии.
- Контакт — Instagram `@qajet.io`, указанный на последнем слайде.
- Оригинальный PDF доступен по `/startupbattle/QAJET-pitch.pdf`.

## Дизайн и доступность

Используются существующие цвета, системный шрифт, радиусы и `BarGrow` из
дизайн-системы QAJET. CSS ограничен модулем страницы. Галерея поддерживает
стрелки, Home/End, семантику вкладок и открытие исходного изображения.
Полная стоимость доступна текстом; детализация — в нативном `details`.

При проверке reduced motion обнаружено различие первого клиентского рендера
и SSR в общем motion-provider. Исправлена синхронизация гидратации, а BarGrow
использует постоянное начальное состояние и нулевую длительность/задержку
при reduced motion. Браузерный тест проверяет отсутствие ошибки гидратации
и ненулевую видимую ширину полосы.

## Проверки

```sh
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm --filter @qajet/web build
```

Использовать pnpm 10.33.0 из `packageManager`. Для проверки публичной страницы
на уже запущенном сервере или Vercel:

```sh
PLAYWRIGHT_BASE_URL=https://YOUR_DEPLOYMENT pnpm --filter @qajet/web exec playwright test e2e/startupbattle.spec.ts --workers=1
```

Тест не требует аккаунтов или базы данных и не создаёт заказов. Проверяет
HTTP 200, PDF, метаданные, переключение всех экранов, клавиатуру, якорные
ссылки и ширины 320, 375, 768, 1440 px.

## Vercel

Используется существующий проект `qajet`, Root Directory: `apps/web`.
Команды Vercel выполняются из корня монорепозитория:

```sh
vercel link --project qajet
vercel deploy
```

Новый маршрут не требует переменных окружения. Наличие локальной сборки
само по себе не подтверждает деплой: нужно дождаться READY и проверить
`/startupbattle` и PDF на полученном URL. Preview может быть защищён входом
Vercel; для публичного показа нужен production-домен или доступный preview.
